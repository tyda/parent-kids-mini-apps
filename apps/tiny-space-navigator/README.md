# 星際導航密語

適合親子玩 5–10 分鐘的純前端合作遊戲。一人先記住 5×5 地圖上的隕石，再把隕石藏起來，以「上、下、左、右」口頭提示另一人操作太空船。共三關，每關交換角色。

## 開啟方式

直接開啟 `index.html`，或在 repository 根目錄啟動靜態 HTTP server 後瀏覽 `apps/tiny-space-navigator/`。

## 設計與隱私

- 手機直向與橫向皆可操作，支援方向鍵與鍵盤方向鍵。
- 不需帳號、網路 API、相機或照片。
- 遊戲內容只存在目前頁面，不收集或上傳資料。
