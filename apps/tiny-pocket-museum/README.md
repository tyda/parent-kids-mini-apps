# 口袋博物館

純前端親子策展遊戲，適合兩人以上、5–15 分鐘，手機直向與橫向皆可玩。

## 玩法

1. 輪流當館長，在主題下從八張 emoji 圖卡中挑三件展品；再點可取消。
2. 館長解釋用途，訪客問一個問題。沒有標準答案，重點是聆聽與想像。
3. 按換人策展，五回合完成後看展。孩子可指圖，由大人代說。

不必走動或找實物；駕駛不可操作。沒有倒數壓力，也沒有錄音或照片權限。

## 執行與驗證

在 repo 根目錄執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/apps/tiny-pocket-museum/`。
`node apps/tiny-pocket-museum/test-core.js` 驗證不重複牌組、三件上限、取消選取、未選滿阻擋、五回合及重新開始。

所有連結均相對路徑，支援部署於 `/kids/`。Service Worker 僅控制本 app 目錄，僅清除自身前綴快取，不控制根站。首次成功連線快取後支援離線載入。

狀態僅留記憶體，重整清空；重新抽題會先確認未完成的展覽。沒有帳號、外部資源、追蹤、上傳、個人資料或 localStorage。圖像皆為系統 emoji，不含照片。
