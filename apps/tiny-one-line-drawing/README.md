# 一筆猜猜畫

適合兩人輪流玩的手機畫圖猜題遊戲，約 5–10 分鐘完成。

## 玩法

1. 畫家偷看手機上的簡單題目。
2. 按下「藏好題目，開始畫」，把手機交給猜的人看畫板。
3. 畫家用手指畫圖，不能寫字或說出答案。
4. 猜到按「猜到了」獲得一顆星；五回合中每回合交換角色。

計時可以暫停，不追求速度；沒有網路時，曾開啟過的版本仍可透過 service worker 使用。

## 本機執行與測試

```bash
python3 -m http.server 8000
node test-core.js
```

開啟 `http://localhost:8000/apps/tiny-one-line-drawing/`。
