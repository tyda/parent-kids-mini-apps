# 小小地圖謎案

一支手機、兩個人的合作推理遊戲，一場約 5–15 分鐘。小鎮有三件東西被藏起來了，大家一起用線索在小地圖上「排除」格子，找出藏匿點；破完三案後，用收集到的三條證據從八位嫌疑犯中指認調皮鬼。

## 怎麼玩

1. 選難度：見習偵探（4×4、每案 3 張線索）或資深偵探（5×5、每案 4 張線索，多了步數線索）。
2. 一人念線索，另一人打叉；每翻一張新線索就換人。
3. 把不可能的格子打叉。地標格不藏東西。不確定時按「檢查我的叉」。
4. 選「搜查」工具，點一格並確定：
   - 每案基本 3 顆星，每搜錯一次少 1 顆（最少 1 顆）。
   - 線索沒翻完就找對，多得 1 顆「大膽獎」，所以要一起討論：現在就搜，還是再翻一張？
5. 每破一案得到一條證據（耳朵、穿戴、點心）。三條都到手後指認調皮鬼，一次成功得 2 顆星，指認錯會說明哪一條證據對不上。

這款的核心是「用條件排除可能性」的邏輯推理；和合集裡靠記憶走路線的星際導航密語、交換暗號的暗號電台玩法不同。

## 設計

- 每張地圖由種子產生。線索保證同時成立時只剩一格，且少任何一張都解不出來，所以每張線索都有用，提早搜查一定有賭注。
- 「檢查我的叉」只比對已翻開的線索，不會看答案。
- 格子同時用圖示、座標、✕ 記號和文字標籤區分，不只靠顏色；進度和結果用 `aria-live` 播報。
- 鍵盤：方向鍵移動、空白鍵打叉、Enter 搜查（需確認）、N 翻新線索、C 檢查、Esc 取消搜查。
- 手機直向、橫向都可操作；橫向時地圖在左、線索在右。`prefers-reduced-motion` 時關閉動畫。
- 不需帳號、網路 API、照片或任何權限，所有圖案都是系統 emoji；只在 `localStorage` 記一個「看過玩法」的旗標。
- Service Worker 只快取並控制本工具目錄，首次載入後可離線開啟。

## 開啟與測試

用靜態 HTTP server 開啟本目錄的 `index.html`（或從合集首頁進入）。

```bash
node test-core.js
```
