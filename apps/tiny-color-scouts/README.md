# 小小顏色搜查隊

適合親子在車上、等餐、排隊或週末短暫空檔玩的安靜合作觀察遊戲。

## 玩法

1. 每回合抽出一個有文字與圖案提示的顏色，以及一個觀察任務。
2. 小朋友與大人輪流找身邊符合條件的物品，找到後按自己的按鈕並分享答案。
3. 兩人都找到才完成回合；完成 5 回合，全隊一起過關。找不到可換卡，不扣分。

## 本機執行

在 repository 根目錄執行：

```bash
python3 -m http.server 8000
```

開啟 `http://localhost:8000/apps/tiny-color-scouts/`。

## 測試

```bash
node apps/tiny-color-scouts/test-core.js
```
