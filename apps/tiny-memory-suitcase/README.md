# 記憶旅行箱

適合兩位以上親子在等餐、排隊、車上或睡前玩的低音量記憶接龍。玩家輪流記住旅行箱內的物品順序、蓋上答案口頭重述，再加入一件新物品。

## 特色

- 3、5、7 件三種長度，約 3–8 分鐘
- 不計分、不淘汰；忘記時可直接看答案繼續
- 物品選項每局隨機且不重複
- 記錄此裝置完成過的最高件數
- 手機直向與橫向版面、鍵盤操作及減少動態效果支援
- 純前端、無外部資源，可離線快取

## 執行與測試

直接開啟 `index.html`，或在 repository 根目錄啟動靜態伺服器：

```bash
python3 -m http.server 8000
node apps/tiny-memory-suitcase/test-core.js
```
