# 小小暗號電台

一支手機、兩個人的合作解碼遊戲，適合等餐、候車、睡前 5–15 分鐘。每回合一人當「編碼員」，一人當「解碼員」：

1. 選訊息長度（2 或 3 個圖案）與回合數（4 或 6）。
2. 解碼員轉身，編碼員按「偷看任務」看祕密圖案，對照本回合密碼本，把每個圖案換成兩個燈號（紅圓 ●、黃三角 ▲、藍方塊 ■）。
3. 按「送出訊號」後畫面遮住答案，交給解碼員按「打開接收器」。
4. 解碼員只看到燈號與密碼本，選出圖案後一起揭曉；每猜對一個得 1 顆團隊星星，下一回合交換角色。

每回合會換新的密碼本、祕密訊息與小任務卡（安靜任務、可問一個是非題等），任務卡只是玩法建議，不會扣分。

## 設計

- 燈號同時用顏色、形狀、文字區分，色弱也能玩；按鈕有螢幕閱讀器標籤，進度用 `aria-live` 播報。
- 支援鍵盤 1／2／3 輸入燈號；`prefers-reduced-motion` 時關閉閃爍與縮放動畫。
- 手機直向、橫向都可操作；寬螢幕時密碼本放在右側。
- 不需帳號、網路 API、照片或任何權限；只在 `localStorage` 記一個「看過玩法」的旗標。
- Service Worker 只快取本工具目錄，首次載入後可離線開啟。

## 開啟與測試

用靜態 HTTP server 開啟本目錄的 `index.html`（或從合集首頁進入）。

```bash
node test-core.js
```
